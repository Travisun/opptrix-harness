Doc Demo — 文档解析

上传 text/plain 文件后自动解析行数 / 词数 / 字符数， 结果以 doc-parse 卡片发送到 general 频道。

手动解析

调用 POST /ext/doc-demo/parse（鉴权 token 由父页面注入到 ?token=）：

fetch('/ext/doc-demo/parse?token=' + token, {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ fileId: '<文件 ID>' }),
}).then((r) => r.json());
// => { "fileId": "…", "lines": 2, "words": 4, "chars": 24 }
